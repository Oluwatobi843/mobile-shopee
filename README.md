# Mobile Shopee

> A responsive e-commerce interface built with HTML/CSS and Sass, focused on product presentation and shopping-oriented UI.

## Overview

Mobile Shopee is a frontend e-commerce project demonstrating responsive page composition, product-oriented layouts and Sass-based styling. The repository uses Sass to compile the main stylesheet from `sass/style.scss` into CSS.

## Technology stack

- HTML
- CSS
- Sass
- npm

## Styling workflow

```text
Sass source
sass/style.scss
      |
      v
Sass compiler
      |
      v
style.css
      |
      v
Browser UI
```

## Installation

```bash
git clone https://github.com/Oluwatobi843/mobile-shopee.git
cd mobile-shopee
npm install
```

## Development

The repository's configured start script watches the Sass source and compiles changes into CSS:

```bash
npm start
```

## Engineering value

This project demonstrates **responsive frontend styling, Sass workflows, component/page layout thinking and e-commerce UI development**.
